# 🍽️ RecipeVerse AI – Intelligent Recipe Generator Using Generative AI

RecipeVerse AI is an AI-powered recipe recommendation web application that generates personalized recipes based on the ingredients available with the user. Users can either type the ingredients manually or upload an image of ingredients, and Google Gemini AI intelligently recognizes the ingredients to generate realistic, healthy, and easy-to-follow recipes.

The application helps reduce food waste by recommending recipes using ingredients already available at home while making meal planning faster and more convenient.

---

## 🚀 Features

- 🥕 Enter ingredients manually
- 📷 Upload ingredient images

## ⚙️ How It Works

1. User enters ingredients manually or uploads an image.
2. Google Gemini AI identifies the ingredients.
3. AI analyzes the available ingredients.
4. Personalized recipes are generated instantly.
5. Users receive:
   - Recipe Name
   - Ingredients List
   - Cooking Instructions
   - Preparation Time
   - Cooking Time
   - Nutritional Information
   - Alternative Recipe Suggestions

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/RecipeVerse-AI.git
```

Go to the project directory:

```bash
cd RecipeVerse-AI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory.

```env
REACT_APP_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
REACT_APP_FIREBASE_API_KEY=YOUR_FIREBASE_API_KEY
REACT_APP_FIREBASE_AUTH_DOMAIN=YOUR_AUTH_DOMAIN
REACT_APP_FIREBASE_PROJECT_ID=YOUR_PROJECT_ID
REACT_APP_FIREBASE_STORAGE_BUCKET=YOUR_STORAGE_BUCKET
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID
REACT_APP_FIREBASE_APP_ID=YOUR_APP_ID
```
